# Session 2.1 — Masters: stations, firms, trucks, drivers

## Goal
The client can type all their master data fast, by keyboard, before go-live (fresh start: masters are the only
thing they enter up front). Every later screen picks from these lists. This is also the first real keeper
endpoint that writes business rows, so it sets the pattern every later endpoint copies.

## Decided rules for this slice
**Keeper endpoints** (named routes, one SQL each, seat header, audit row in the same transaction, `KEEPER_VERSION` bump)
- `masters.all()` → every station, firm, truck and driver (active and inactive) in one call. Small tables: the
  screen keeps them in memory and searches there. Ordered by name / number, never by `id`.
- Per kind: `create(fields)`, `update(id, version, fields)`, `setActive(id, version, active)`.
  Stale `version` → refused with the current row so the screen can show what changed.
- **No delete.** Deactivate only: inactive rows stay for old LRs and reports, and disappear from pick lists.
- Every write returns the saved row.

**Duplicate rules** (in the keeper; pure helpers tested)
- Stations, firms: same `nameKey` as an existing row (active or not) → refused: "Already exists: <name>"
  (and offers to reactivate it if it is inactive).
- Firms: a name that starts like an existing one, or one existing name starting like it (on `nameKey`) → the
  keeper answers `similar: [names]` and saves only when the request is resent with `confirmSimilar: true`.
- Trucks: `number_key` = uppercase with spaces, dots and dashes removed (`mh-29 be 1234` → `MH29BE1234`);
  same key → refused. Shown as typed, uppercased.
- Drivers: same name **and** same phone → refused; same name only → `similar`, as for firms.
- Firm station is optional (from the station list). Phone is optional, digits only, stored as text.

**PIN**
- Adding needs no PIN (clerks will add walk-in firms from LR entry too).
- Editing a name/number or deactivating needs the **System PIN**, checked by the keeper in the same request.

**Screen — Masters page** (direction A components from 1.5)
- Four tabs: Stations · Firms · Trucks · Drivers, each with a count.
- Left: table of that kind (search box filters in memory on `nameKey`; "Show inactive" toggle; inactive rows
  greyed with an Inactive chip). Right: the add/edit form.
- **Fast add:** Enter moves through the fields; on the last field Enter saves; the form clears and focus goes
  back to the first field, ready for the next one. A success toast per save ("Firm saved: …").
- Similar-name answer → a confirm Dialog listing the similar names ("Add anyway" / "Go back").
- Click a row (or select it and press Enter) → edit in the same form → Save asks the System PIN.
- Deactivate / Reactivate button on the selected row (System PIN for deactivate).
- Firm's station uses the TypeAhead (stations only, active only). If the TypeAhead list is clipped by the card
  (1.5 known issue), fix it here: render the list outside the card (portal) — needed again on LR Entry.
- The screen refetches `masters.all()` after its own writes and when the page is opened. (Live updates from
  other seats arrive in 2.2 with keeper change events.)
- All text in `src/strings.ts`.

## Tests
- Pure: `truckKey`, similar-name finder (prefix both ways on `nameKey`), phone cleaning.
- Database (`*.dbtest.ts`) per kind: create; exact duplicate refused (case/space/punctuation variants);
  similar → needs confirm → saves; update with stale version refused; deactivate hides from active list but row
  stays; reactivate; audit row per write in the same transaction; wrong System PIN refused and nothing written.
- **End-to-end marker test promised since 1.3:** create a master through the real keeper route, shorten the
  marker interval for the test, assert the blank-database marker's `businessRows` rose.
- Real-keeper test: two seats create the same station name at the same moment → one saved, the other refused.

## Out of scope
Change events / live refresh across seats (2.2), LR entry (2.2), importing masters from a file or from DM
(ask the owner first — see Done when), Agent master (deferred), shortcuts (2.4).

## Done when
1. All tests pass inside `npm run check`.
2. Keyboard only: add 10 stations, 10 firms (with station), 5 trucks, 5 drivers without touching the mouse;
   each save clears the form and returns focus to the first field.
3. Duplicate and similar rules behave as above on screen (try "shree ganesh traders " vs "Shree Ganesh Traders",
   "MH 29 BE 1234" vs "mh-29-be-1234").
4. Edit and deactivate ask the System PIN; a deactivated firm disappears from the firm station pick list
   equivalents and shows under "Show inactive".
5. Restart the app: everything is still there; the blank-database guard now has a non-zero baseline.
6. `HANDOFF.md` updated; changed files listed with one suggested commit message and the worktree steps
   (commit and confirm before removing the worktree — never `--force`).
