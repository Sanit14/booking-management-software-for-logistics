# Session 1.1 — Project skeleton

## Goal
An empty Booking Manager app that builds and opens: Electron 22 window, React screen, TypeScript everywhere,
and one `npm run check` command that the Stop hook can trust.

## Decided rules for this slice
- Electron exactly `22.3.27`. Vite `build.target: 'chrome108'`. React 19 + TypeScript (strict).
- Main window: 1024×768 default, min 1024×768, `contextIsolation: true`, `nodeIntegration: false`,
  `sandbox: true`, no remote URLs (dev server only in dev), single-instance lock named for Booking Manager.
- Preload exposes nothing yet except an app version string (the keeper bridge comes in 1.2).
- Electron main + preload written in TypeScript, compiled to CommonJS targeting Node 16.
- Folder layout:
  - `electron/` main + preload
  - `src/` React screen (one placeholder page: "Booking Manager" title, version)
  - `shared/` types shared by screen and keeper (empty index for now)
  - `docs/`, `.claude/` already exist
- Scripts (PowerShell-friendly, no bash-only syntax):
  - `npm run dev` — Vite + Electron together
  - `npm run build` — typecheck + Vite build + compile electron
  - `npm run check` — typecheck (all projects) + lint + `node --test` (passes with zero tests)
- ESLint flat config, TypeScript-aware, React hooks rules. No Prettier (not needed).
- Only the dependencies this slice needs. Check `npm ls` before adding anything.

## Out of scope
Keeper, database, styling/tokens, fonts, sidebar, installer, updater, any business logic.

## Done when
1. `npm install` then `npm run dev` opens a 1024×768 window titled "Booking Manager" showing the placeholder page.
2. A second launch focuses the first window instead of opening another.
3. `npm run check` passes; `npm run build` passes and the built JS targets chrome108.
4. `git status` shows only intended files (`.gitignore` covers node_modules, builds, *.db).
5. `HANDOFF.md` updated; changed files listed with one suggested commit message.
