# Session 1.6 — plan

**Primary goal:** one installer puts Booking Manager on the Windows 7 host for every seat, beside DM, and the app
stays usable when the seat that started the keeper logs off.

Facts read first: DM is installed on this PC (`C:\Program Files\DeliveryManager`), nothing listens on 47615/47715 now,
`C:\BookingManagerData`, `C:\ProgramData\BookingManager` and `D:\BookingManagerBackups` already exist here, **this
worktree has no `node_modules`** (needs `npm install` + `npm run postinstall`, ~8 min). DM ships electron-builder
**26.15.3**, win-x64 NSIS, `perMachine`, `asarUnpack` better-sqlite3, keeper = `process.execPath` + `ELECTRON_RUN_AS_NODE`
on a script inside `app.asar` (same as ours, so it works packaged).

## Slice 0 — setup
`npm install -D -E electron-builder@26.15.3` (also restores node_modules), then `npm run postinstall`, `npm run check` green.

## Slice 1 — watchdog (test first)
- New `electron/watchdog.ts` (pure): `KEEPER_PING_MS = 15000` and `keeperAction(probe, expectedVersion)` →
  `ok | wait | start | replace | wrong-app`. Test `electron/watchdog.test.ts` with fake probes: healthy, safe-mode healthy,
  starting, down+refused, down+timeout, foreign, version older, version newer.
- `electron/keeperBridge.ts`: `resolveStatus` uses `keeperAction` for its replace / start decisions (no behaviour change);
  new `recover()` = push `reconnecting`, `status()` (already re-probes and respawns), push the result. Called by a
  `setInterval(KEEPER_PING_MS)` tick when the action is `start`/`replace` (or the screen shows `keeper-unreachable` and the
  keeper is back), and by `call()` on any failed request. Logs `watchdog-restart` to keeper.log. The ping is the only polling.
- `shared/keeper.ts`: `KeeperPush = KeeperStatus | {kind:'reconnecting'}`, `KeeperApi.onStatus(cb) → unsubscribe`;
  `electron/preload.ts` wires `keeper:status`. `src/App.tsx` listens; `StatusBox` shows "Reconnecting…" (amber dot).

## Slice 2 — version info in Settings (keeper change)

## Slice 4 — packaging

  files `dist/**`, `dist-electron/**` minus `*.test.js`, `*.dbtest.js`, `*.map`; `asarUnpack` better-sqlite3;
  `npmRebuild:false` because `postinstall` already built it for Electron 22; NSIS x64, perMachine, not one-click,

  Script `"dist": "npm run build && electron-builder --publish never"`.
