# Session 4.4 closing — plan (the audit's open items, decided)

Written before any code. Nothing below is built yet. Card: `docs/sessions/4.4-closing.md`. Audit: `docs/audit-4.4.md`.

## Primary goal
Before the pilot, every High / Medium in the audit has an owner decision **and** either a fix with a test that failed first or an accepted-gap line, the dead code is gone, and
release **0.3.2** can be cut from pushed code. A clerk notices only two new messages (O3, O5); nothing else changes on screen.

## Veto points (I took these defaults; say if you want another)
1. **O3 compares against the saved row, no migration.** A retry (same `uid`) is "the same" when date (if sent), stations, parties (firm id, or the cleaned name), particular, qty, every amount, option and tax % equal the stored LR; a memo: date (if sent), truck, driver, stations, hire, hamali and the set of LRs on it. Anything else, or a retry with invalid values, is `lr-already-saved` / `memo-already-saved`. A retry that arrives after another seat edited the LR is also refused with the number (harmless: nothing is written).
2. **O4 counts per seat, in memory.** A "failed start" = a keeper this seat spawned exits non-zero (a 60 s timeout is not counted). 3 within 10 minutes → this seat stops spawning and shows the card's sentence; restarting the app resets it. The pre-migration backup is skipped when the newest backup is under 60 min old **and** its own schema version equals the book's (an ordinary hourly or update-time backup at that version counts: the updater makes one seconds before every update).
3. **O5 "Refresh"** drops the pages below the first and shows page 1 again (Load more again if needed).
4. **O6 harness uses the fixed keeper port 47715**, so it refuses to run while Booking Manager is open; it is a `npm run` script, **not** part of `npm run check`. "Over 100 ms" is judged on the **median** keystroke / event; the worst is recorded too.
5. **Print guard** refuses (existing `print-too-long` / `report-too-long` wording) when the real `data:` URL is over 2 MB. A 500-LR memo of long Devanagari names would also be refused. One line (base64 when shorter) would let those print — not done unless you ask.
6. **O8**: `headersTimeout = requestTimeout = 30 s` (test hook `BM_REQUEST_TIMEOUT_MS`, only with `--test-hooks`). Pruning seats older than 30 days does not stop a flood of new names inside 30 days; only the card's fix is made.
