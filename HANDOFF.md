## For the next session to know
1. `src/logic/reportPages.ts` is the Reports paging rule (first page replaced on a change, pages below kept and marked old; `withMorePage(…, outdated)` for a Load more that crossed a change). `src/useShowMore.ts` + `src/logic/showMore.ts` draw 200 rows and "Show more" for the LR Entry day list and Masters; a new long list should use them.
2. `makeStartGuard` (`electron/watchdog.ts`) is per seat, in memory and latched; `keeper-start-failed` is its error code. The keeper's `sendResult` and the bridge's `call` send only OS error codes (`keeper/errno.ts`): never put a path or a name in a `failed` detail.
3. `npm run measure:ui` (real window, keeper port 47715: close Booking Manager first) and `node scripts/test-installer.cjs` (needs the NSIS cache from `npm run dist`) are not part of `npm run check`.
4. Same as 4.4: `npm run check` fails by chance when the PC is busy; the Stop hook runs a check in the MAIN folder and collides with one you run elsewhere.
